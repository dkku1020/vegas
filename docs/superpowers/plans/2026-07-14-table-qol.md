# Table Quality-of-Life Changes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Free Hand" button (deals/settles a hand with zero wager), a "Rebet" button (re-places the previous hand's full bet distribution), and move the Tie bet spot to the middle of the table.

**Architecture:** Two new `GameAction` variants (`FREE_HAND`, `REBET`) added to the existing `gameReducer.ts` reducer, plus a new `lastBets: Bets | null` field on `GameState` that `DEAL` populates and `FREE_HAND` leaves untouched. `Table.tsx` gains two new buttons wired to these actions and reorders its `SPOTS` array so Tie renders between Player and Banker.

**Tech Stack:** React, TypeScript, Vitest + @testing-library/react (existing stack, no new dependencies).

## Global Constraints

- Table min/max bet stay `TABLE_MIN_BET = 5`, `TABLE_MAX_BET = 500` (from `src/renderer/src/state/gameReducer.ts:8-9`) — unchanged by this work.
- Button copy is exactly `Free Hand` and `Rebet` (existing buttons are `Clear`, `Deal`, `Next Hand` — match that plain-word style).
- Betting-phase control button order: `[Rebet] [Clear] [Free Hand] [Deal]`.
- Bet spot order: `['player', 'tie', 'banker']` (Tie in the middle).
- Free Hand refunds any bets on the table and settles with a zero `Bets` object (`netChange` always 0); it is enabled any time the table is in the `betting` phase.
- Rebet only re-places a bet (never auto-deals); it is enabled only when the table currently has zero bets AND a non-null `lastBets` exists AND its total is `<=` current bankroll.
- `FREE_HAND` must never overwrite `lastBets` — Rebet always targets the last hand that had a real (non-zero) wager.

      if (state.phase !== 'betting') return state
      if (!state.lastBets) return state

      }
    }
